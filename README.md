# Tic-Tac-Toe Game

A simple two-player Tic-Tac-Toe game built as a programming and frontend practice project.

## Features

- Two-player gameplay
- Turn-based interaction
- Win-condition detection
- Draw detection
- Game reset/restart flow
- Simple responsive interface

## Purpose

This project focuses on implementing game logic, managing application state, handling user interactions, and building a clean browser-based experience.

## Getting Started

```bash
git clone https://github.com/sanjayt2706/tic-tac-toe-game.git
cd tic-tac-toe-game
```

Open the project files in a browser or use the development workflow appropriate to the technologies currently present in the repository.

## Concepts Practiced

- Conditional logic
- Arrays/state representation
- Event handling
- DOM/UI updates
- Win and draw algorithms
